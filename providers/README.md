Provider logos are bundled locally so the search picker works offline.

- Google, DuckDuckGo, Brave, Kagi, Startpage and Ecosia: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0 1.0 Universal.
- Bing: [Bootstrap Icons](https://github.com/twbs/icons), MIT license.

The logos are used to identify the corresponding search providers.
